# MeTube App

This add-on provides a web interface for yt-dlp downloads.

Having a media server to view the files later would be nice.

You can install a media server from the apps and then point it to /media/metube to list and view the files.

I recomend mounting the files from a NAS server, using network storage options, to keep Home-assistant effort and space to other tasks.

## Configuration

```yaml
download_path: /media/metube
