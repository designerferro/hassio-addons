# Home Assistant Add-on: MeTube

Download videos directly into Home Assistant media folders.

It's onçu a wrapper to add https://github.com/alexta69/metube to the inner docker that exists in hassio OS.

## Features
- YouTube downloads
- Plex-compatible media paths
- Ingress support
- Persistent queue

## Installation
- Add this repository (https://github.com/designerferro/hassio-addons) to the Home Assistant Add-on Store.
- Open the app store (used to be add-on store).
- Select install.
